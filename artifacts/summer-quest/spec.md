# Summer Quest RPG — spec (웹 1차 MVP)

> 이 spec은 [idea.md](./idea.md)의 Recommended Direction·Resolved Decisions를 전제로 한다.
> WHAT(외부 관찰 가능한 동작)만 다룬다. 저장소 구현·파일 배치·config 위치·테스트 유형은 plan.md 소관이다.

## 개요

두 자녀가 "공부"가 아니라 "게임"으로 느끼도록, `이번 주 계획 → 오늘의 퀘스트(자동 생성) → 클리어 → EXP·코인·레벨·아바타 성장`을 한 화면 흐름으로 관통시킨다. 사용자는 프로필을 전환하며 자녀의 성장 루프와 부모의 길드 샵 관리를 한 브라우저에서 경험한다.

## 범위

### 포함
- 상단 프로필 전환 토글 (자녀A · 자녀B · 부모, 로그인 없음)
- 이번 주 모험 계획: 항목별 `일일 목표량 + 수행 요일(월~금 중 다중 선택)` 설정·수정
- 오늘의 퀘스트: 주간 계획에서 결정적 규칙으로 자동 생성, 완료 체크·해제
- 성장 반영: 완료당 EXP·코인 지급, 레벨업, **레벨 연동 아바타**(외형·칭호), streak, 전체 완료 특별 메시지
- 길드 샵: 부모가 보상 등록, 자녀가 코인으로 즉시 교환, 부모는 교환 내역 확인
- 첫 진입 시 시드 데이터 프리필
- **재미 연출**: 완료 연출(획득량 팝업·EXP바 전환·캐릭터 반응), 오늘의 진행 게이지 + 전체 완료 보너스·컨페티, 업적 뱃지, streak 마일스톤 보상

### 제외 (MVP 이후 개선 후보 — 이유와 재도입 시점)
- **Supabase / Auth / RLS**: 1차 목표는 루프 검증. 저장소는 추상화 뒤에 두고, 루프가 검증되면 어댑터 교체.
- **모바일 / PWA / 터치 최적화**: "웹 1차" 명시 합의. 데스크톱 검증 후 확장.
- **적응형 목표 추천(80%/50% 규칙)**: hypothesis 성격. 정적 안내로 대체하고, 루프 검증 뒤 도입.
- **용돈 보상 시스템**: 코인 루프가 먼저 검증돼야 위에 얹을 수 있음.
- **주간 회고 / 모험 일지**: 핵심 루프 밖. 데이터가 쌓인 뒤 의미 생김.
- **형제 경쟁**: 자녀 1인 루프가 먼저. 2인 데이터가 있어야 성립.
- **부모 대시보드(진행 분석)**: 자녀 루프가 데이터를 만든 다음의 소비 화면.
- **캐릭터 꾸미기(코인으로 외형 아이템 구매)**: 검증 안 된 코인 루프 위에 얹는 오버엔지니어링. 코인 루프 검증 후 도입.
- **난이도별 EXP·코인 차등**: 완료당 고정값으로 시작. 루프 검증 후 도입.

## 시나리오

> 퀘스트 생성 규칙(전 시나리오 공통): 계획 항목에서 **사용자가 직접 선택한 요일**에만 오늘의 퀘스트로 생성된다. 자동 매핑·랜덤은 없다.

### S1. 프로필 전환
- **Given**: 상단에 자녀A · 자녀B · 부모 3개 프로필 토글이 보인다
- **When**: 다른 프로필을 선택한다
- **Then**
  - [x] S1-1 자녀B 선택 → 화면이 자녀B의 진행 상태(EXP·코인·레벨·계획·오늘의 퀘스트)로 전환된다
  - [ ] S1-2 부모 선택 → 길드 샵 관리(보상 등록 + 교환 내역) 화면으로 전환된다
  - [x] S1-3 어떤 프로필도 PIN·로그인 없이 즉시 진입한다 (부모 포함)

### S2. 이번 주 모험 계획 세우기
- **Given**: 자녀A 프로필의 이번 주 계획 화면
- **When**: 계획 항목을 추가·삭제·수정한다
- **Then**
  - [x] S2-1 이름="수학 문제", 목표량=20, 요일=월·수·금 선택 후 추가 → 계획 목록에 "수학 문제 20개 · 월·수·금" 항목이 나타난다
  - [ ] ~~S2-2~~ (삭제: 주간 빈도(1~5) 개념 폐기 → 요일 직접 선택으로 대체. S2-5로 재발급)
  - [x] S2-3 항목을 삭제하면 계획 목록에서 사라진다
  - [x] S2-4 이미 계획이 있는 주에도 "이번 주 계획 수정"으로 항목을 추가·삭제할 수 있다
  - [x] S2-5 수행 요일은 월~금 중 자유롭게 다중 선택하며, 최소 1개는 선택해야 추가된다 (0개 선택 시 추가 불가)

### S3. 오늘의 퀘스트 자동 생성 (결정적)
- **Given**: 자녀A에 "수학 문제 20개 · 월·수·금" 계획이 있다
- **When**: 특정 요일에 오늘의 퀘스트 화면에 진입한다
- **Then**
  - [x] S3-1 월요일 진입 → 오늘의 퀘스트에 "수학 문제 20개"가 나타난다 (월 선택됨)
  - [x] S3-2 화요일 진입 → "수학 문제 20개"가 나타나지 않는다 (화 미선택)
  - [x] S3-3 토·일요일 진입 → 오늘의 퀘스트가 없다 (요일 선택은 월~금만 가능)
  - [x] S3-4 같은 요일에 여러 번 진입해도 동일한 퀘스트 집합이 나타난다 (결정적, 랜덤 없음)

### S4. 퀘스트 완료 → 성장 반영
- **Given**: 자녀A, 오늘의 퀘스트 "수학 문제 20개" 미완료, EXP 0 · 코인 0
- **When**: 해당 퀘스트를 완료 체크한다
- **Then**
  - [x] S4-1 완료 표시(체크·취소선)가 나타난다
  - [x] S4-2 EXP가 10으로 표시된다 (완료당 +10, 제안 기본값)
  - [x] S4-3 코인이 5로 표시된다 (완료당 +5, 제안 기본값)
  - [x] S4-4 오늘의 퀘스트 화면 진입 후 한 퀘스트를 완료 상태로 만들기까지 클릭 3회 이하

### S5. 완료 되돌림 → 보상 회수
- **Given**: 자녀A, "수학 문제 20개"가 완료 상태, EXP 10 · 코인 5
- **When**: 완료를 해제한다
- **Then**
  - [x] S5-1 미완료 표시로 돌아간다
  - [x] S5-2 EXP가 0으로 표시된다 (지급분 회수)
  - [x] S5-3 코인이 0으로 표시된다 (지급분 회수)

### S6. 레벨업 + 아바타 변화
- **Given**: 자녀A, Lv1(0 EXP부터), EXP 40 (Lv2 임계 50, 제안 기본값)
- **When**: 퀘스트를 완료해 EXP가 50 이상이 된다
- **Then**
  - [x] S6-1 EXP 50 도달 → 레벨이 Lv2로 오르고 레벨명·칭호가 Lv2 것으로 표시된다
  - [x] S6-2 레벨업 시 아바타 외형이 Lv2 티어의 것으로 바뀐다
  - [x] S6-3 레벨업 순간 축하 메시지가 나타난다
  - [x] S6-4 완료 회수로 EXP가 50 미만이 되면 레벨·칭호·아바타가 Lv1로 되돌아간다 (INV-1 연계)
  - [x] S6-5 레벨업 순간 아바타 변화가 강조되는 진화 연출(확대·전환 등 강조 상태)이 나타난다

### S7. Streak
- **Given**: 자녀A
- **When**: 배정된 날의 퀘스트를 전부 완료하는 날이 이어진다
- **Then**
  - [x] S7-1 오늘 배정 퀘스트를 전부 완료 → streak가 1 증가해 표시된다
  - [x] S7-2 배정 퀘스트가 있는 날에 전체 완료가 아니면, 다음 배정일에 streak가 0으로 끊긴다
  - [x] S7-3 퀘스트가 없는 날(주말)은 streak를 끊지도 늘리지도 않는다

### S8. 전체 완료 특별 메시지
- **Given**: 자녀A, 오늘 배정 퀘스트 여러 개 중 마지막 하나가 미완료
- **When**: 마지막 퀘스트를 완료한다
- **Then**
  - [x] S8-1 오늘 배정분 전체 완료 → "오늘의 모험을 전부 클리어했어요! 🎉"(제안 기본값)가 나타난다
  - [x] S8-2 하나라도 미완료면 특별 메시지가 나타나지 않는다

### S9. 길드 샵 — 부모 보상 등록
- **Given**: 부모 프로필의 길드 샵 관리 화면
- **When**: 보상을 등록·삭제한다
- **Then**
  - [x] S9-1 이름="치킨 먹기", 가격=50 등록 → 보상 목록에 "치킨 먹기 · 50코인"이 나타난다
  - [x] S9-2 등록한 보상이 자녀 길드 샵 화면에도 나타난다
  - [x] S9-3 보상을 삭제하면 목록에서 사라진다

### S10. 길드 샵 — 자녀 교환 (즉시 차감)
- **Given**: 자녀A 코인 60, 길드 샵에 "치킨 먹기 · 50코인"
- **When**: 교환 버튼을 누른다
- **Then**
  - [ ] S10-1 코인이 즉시 50 차감되어 10으로 표시된다
  - [ ] S10-2 해당 보상이 "교환됨" 상태로 표시된다
  - [ ] S10-3 부모 화면 교환 내역에 "자녀A · 치킨 먹기 · 50코인"이 나타난다

### S11. 코인 부족 시 교환 불가
- **Given**: 자녀A 코인 30, 길드 샵에 "치킨 먹기 · 50코인"
- **When**: 해당 보상을 본다
- **Then**
  - [ ] S11-1 교환 버튼이 비활성 상태다
  - [ ] S11-2 "코인이 부족해요"(제안 기본값)가 표시된다

### S12. 주 경계 — 지난 주 계획 유지
- **Given**: 자녀A, 지난 주에 세운 계획이 있고 EXP·코인·레벨·streak가 쌓여 있다
- **When**: 재계획 없이 새 주(월요일)에 진입한다
- **Then**
  - [x] S12-1 새 주에도 지난 주 계획 그대로 오늘의 퀘스트가 생성된다
  - [x] S12-2 성장 지표(EXP·코인·레벨·streak)가 지난 주 값에서 이어진다 (리셋되지 않는다)
  - [x] S12-3 "이번 주 계획 수정"으로 새 주 계획을 갱신할 수 있다

### S13. 첫 진입 시드 데이터
- **Given**: 기존 데이터가 없는 첫 진입
- **When**: 앱에 진입한다
- **Then**
  - [x] S13-1 자녀A·B 각각에 예시 주간 계획 2~3개가 미리 채워져 있다 (제안 기본값)
  - [x] S13-2 부모 길드 샵에 예시 보상 2~3개가 미리 채워져 있다 (제안 기본값)
  - [x] S13-3 진행 지표는 EXP 0 · 코인 0 · Lv1에서 시작한다

### S14. 퀘스트 완료 연출 (juice + 캐릭터 반응)
- **Given**: 자녀A, 오늘의 퀘스트 "수학 문제 20개" 미완료
- **When**: 해당 퀘스트를 완료 체크한다
- **Then**
  - [ ] S14-1 완료 순간 획득량("+10 EXP · +5코인")이 팝업으로 나타났다 사라진다
  - [ ] S14-2 EXP 바가 새 값까지 채워지는 전환(애니메이션 상태)을 보인다
  - [ ] S14-3 완료에 반응하는 아바타 동작 상태(반응 연출 요소·클래스)가 나타난다

### S15. 오늘의 진행 게이지 + 전체 완료 보너스
- **Given**: 자녀A, 오늘 배정 퀘스트 3개 중 2개 완료
- **When**: 진행 상태를 보고, 마지막 퀘스트를 완료한다
- **Then**
  - [ ] S15-1 오늘 진행 게이지가 "2 / 3"(67%)로 표시된다
  - [ ] S15-2 마지막 완료 → 게이지가 "3 / 3"(100%)이 된다
  - [ ] S15-3 전체 완료 시 보너스 코인(+10, 제안 기본값)이 추가 지급되어 코인에 반영된다
  - [ ] S15-4 전체 완료 시 축하 연출(컨페티/빵빠레 요소)이 나타난다

### S16. 업적 뱃지
- **Given**: 자녀A, 아직 어떤 업적도 달성하지 않음 (뱃지 전부 잠금)
- **When**: 업적 조건을 만족하는 행동을 한다
- **Then**
  - [ ] S16-1 업적 영역에 잠금/해제 상태가 구분된 뱃지 목록이 표시된다
  - [ ] S16-2 첫 퀘스트를 완료하면 "첫 클리어" 뱃지가 해제 상태로 바뀐다
  - [ ] S16-3 업적 해제 순간 획득 알림이 나타난다
  - [ ] S16-4 기본 업적 목록(제안 기본값): 첫 클리어 · Lv5 도달 · 7일 연속 · 첫 교환

### S17. Streak 마일스톤 보상
- **Given**: 자녀A, streak가 마일스톤 도달 직전
- **When**: 마일스톤 일수에 도달한다
- **Then**
  - [ ] S17-1 streak가 마일스톤(제안 기본값 3·7·14일)에 도달하면 보너스 코인이 지급되어 반영된다
  - [ ] S17-2 마일스톤 달성 알림이 나타난다
  - [ ] S17-3 다음 마일스톤까지 남은 일수가 표시된다

## 불변 규칙

- [x] INV-1 **보상 ↔ 완료 일치**: 퀘스트 완료 상태와 EXP·코인 지급이 항상 일치한다. 완료하면 지급, 해제하면 회수된다. 회수로 EXP가 현재 레벨 임계 아래로 내려가면 레벨·칭호·아바타가 그 EXP에 해당하는 티어로 되돌아간다.
- [x] INV-2 **프로필 격리**: 한 프로필의 진행·코인·계획·오늘의 퀘스트는 다른 프로필 화면에 노출되지 않는다. (부모는 관리 목적의 교환 내역만 본다)
- [x] INV-3 **지속성**: 페이지를 새로고침하거나 브라우저를 다시 열어도 모든 프로필의 진행·계획·교환 내역이 유지된다.
- [ ] INV-4 **코인 잔액 일관성**: 표시되는 코인 잔액은 (누적 지급 − 누적 차감)과 항상 일치한다. 잔액보다 비싼 보상은 교환할 수 없다(S11).

모든 시나리오 구현 후, 아래 절차의 실행 증거로 feature 완료를 판정한다.

1. 앱을 실행하고 첫 진입한다 → 자녀A·B 시드 계획과 부모 길드 샵 시드 보상이 보인다 (S13, S1)
2. 자녀A로 이번 주 계획에 "수학 문제 20개 · 주 3회"를 추가한다 (S2)
3. 시스템 날짜를 월요일로 두고 오늘의 퀘스트에 진입 → "수학 문제 20개"가 나타난다. 화요일에는 나타나지 않는다 (S3)
4. 퀘스트를 3클릭 이내로 완료 → EXP·코인이 오르고 완료 표시가 뜬다 (S4). 완료를 해제 → EXP·코인이 회수된다 (S5)
5. 퀘스트를 반복 완료해 EXP 50 도달 → Lv2로 오르고 아바타·칭호가 바뀌며 축하 메시지가 뜬다. 회수로 50 미만이 되면 Lv1로 되돌아간다 (S6, INV-1)
6. 퀘스트를 완료하면 획득량 팝업·EXP바 전환·아바타 반응 연출이 나타난다 (S14). 오늘 진행 게이지가 오른다 (S15)
7. 오늘 배정분을 전부 완료 → streak 증가, 전체 완료 메시지, 보너스 코인, 컨페티가 뜬다 (S7, S8, S15). 조건 충족 시 업적 뱃지가 해제되고 알림이 뜬다 (S16). streak가 마일스톤에 도달하면 보너스가 지급된다 (S17)
8. 자녀A로 길드 샵에서 보상을 교환 → 코인 즉시 차감, "교환됨" 표시. 코인 부족한 보상은 교환 버튼이 비활성이다 (S10, S11, INV-4)
9. 부모로 전환 → 방금 교환한 내역이 보이고, 새 보상을 등록하면 자녀 화면에도 나타난다 (S1, S9)
10. 새로고침 후에도 위 상태가 유지된다 (INV-3). 프로필을 자녀B로 바꿔도 자녀A의 진행이 섞이지 않는다 (INV-2)
11. 시스템 날짜를 다음 주 월요일로 넘겨도 지난 주 계획으로 퀘스트가 생성되고 성장 지표가 이어진다 (S12)

## 미결정 항목

- **완료 회수 시 코인 음수 가능성**: 자녀가 코인을 벌어 소비한 뒤 그 완료를 해제하면(INV-1 회수), 소비한 코인만큼 잔액이 음수가 될 수 있다. 회수를 막을지, 잔액을 0에서 멈출지, 소비된 보상 교환을 함께 되돌릴지 미정. → 구현 중 가장 단순한 규칙을 택하고 사용자와 재확인.
- **레벨 정책 수치·아바타 외형의 톤**: Lv1~Lv5 임계(0/50/150/300/500)와 레벨명은 제안 기본값이며, "고1이 유치하게 느끼지 않는" 절제된 톤은 실제 반응으로만 검증 가능(주관적)이라 spec 기준에 넣지 않음.
