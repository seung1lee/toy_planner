# Summer Quest RPG (웹 1차 MVP)

## Problem Statement
부모의 잔소리 없이 두 자녀(중1여·고1남)가 스스로 목표를 세우고 수행하도록, "공부"가 아니라 "게임"으로 느껴지는 성장 루프를 어떻게 웹에서 최소로 증명할 수 있을까?

## Recommended Direction
**게임 루프 수직 슬라이스.** 한 자녀 시점에서 `이번 주 모험 계획 → 오늘의 퀘스트(자동생성) → 퀘스트 클리어 → EXP·코인·레벨 반영`을 한 흐름으로 관통시킨다. 이 루프가 화면에서 매끄럽게 돌면 "게임 래핑이 동기를 만든다"는 핵심 가정을 눈으로 확인할 수 있고, 안 돌면 나머지 기능(용돈·형제경쟁·부모 대시보드)은 지어봐야 의미가 없다.

**데이터는 localStorage에 두되 `services/` 레이어 인터페이스 뒤로 추상화**한다. 화면·훅은 저장소 구현을 모른 채 인터페이스에만 의존하므로, 후속 단계에서 Supabase 어댑터로 갈아끼우는 것이 화면 수정 없이 가능하다. 이것이 "학습용 데모 → 실사용 확장" 두 목표를 한 번에 만족시키는 이음매다.

**레벨 정책만 `config/`로 분리**한다(원문의 "하드코딩 금지" 요구 + 코드베이스 레이어 규칙과 정합). 나머지 설정 주도 엔진화는 미룬다 — 데모 단계에서 오버엔지니어링이다.

## Key Assumptions to Validate
- [ ] **게임 래핑이 두 연령대 모두에게 동기가 된다** → MVP를 두 자녀에게 실제로 며칠 써보게 하고 "또 하고 싶은가"를 관찰 (데모로는 톤 검증까지만)
- [ ] **고1 남아가 UI를 유치하다고 느끼지 않는다** → 절제된 RPG 비주얼 톤으로 만들고 본인에게 직접 반응 확인
- [ ] **주간 1회 계획 + 일일 3분 이내 사용이 부담을 실제로 줄인다** → 퀘스트 완료가 3클릭 이내로 끝나는지 측정
- [ ] **localStorage 추상화가 Supabase 교체를 실제로 싸게 만든다** → services 인터페이스가 저장소 세부를 완전히 가리는지 코드로 확인

## MVP Scope
**포함 (기능 1·2·3·4의 핵심만):**
- 프로필 전환 토글 (자녀A·자녀B·부모 — 상단, 로그인 없음)
- 이번 주 모험 계획: 항목별 `일일 목표량 + 주간 빈도` 설정, 주 1회
- 오늘의 퀘스트: 주간 계획에서 결정적 규칙으로 자동 생성, 완료 체크
- 성장 반영: 완료 시 EXP·코인 지급, 레벨업, Streak, 전체 완료 특별 메시지
- 레벨 정책은 `config/`에서 관리 (레벨명·필요 EXP)
- 길드 샵: 부모가 등록한 보상 목록을 코인으로 교환 (등록/사용 상태까지, 승인 플로우는 최소)

**빠짐:** 아래 Not Doing 참조.

## Not Doing (and Why)
- **Supabase / Auth / RLS**: 1차 목표는 루프 검증. 저장소는 추상화 뒤에 두고 후속 교체.
- **모바일 / PWA / 터치 최적화**: 웹 1차로 명시적 합의. 반응형은 기본만.
- **적응형 목표 추천 (80%/50% 규칙)**: hypothesis 성격. 정적 안내 문구로 대체하고, 루프가 검증된 뒤 도입.
- **용돈 보상 시스템 (기능 5)**: 코인 루프가 먼저 검증돼야 위에 얹을 수 있음.
- **주간 회고 / 모험 일지 (기능 6)**: 핵심 루프 밖. 데이터가 쌓인 뒤 의미 생김.
- **형제 경쟁 (기능 7)**: 자녀 1명 루프가 먼저. 2명 데이터가 있어야 성립.
- **부모 대시보드 (기능 8)**: 자녀 루프가 데이터를 만든 다음의 소비 화면.
- **Framer Motion / Recharts / Zustand**: 현재 미설치. 루프에 애니메이션·차트·전역상태가 정말 필요해지는 시점에만 추가.

## Resolved Decisions
아래는 초기 Open Questions에 대해 확정된 결정이다. spec 단계는 이 결정을 전제로 시작한다.

- **자동 퀘스트 생성 규칙**: 주간 빈도를 **월~금 고정**으로 배치한다. (요일 선택 UI 없음)
- **코인·EXP 지급**: 퀘스트 **완료당 고정값**. 난이도별 차등 없음.
- **프로필 전환 보호**: 없음. 부모 화면도 PIN 없이 진입.
- **데모 데이터**: 첫 진입 시 **예시 퀘스트를 프리필**한다. (빈 화면이 아니라 시드 데이터로 시작)
